1. Hình Dung Thực Tế: Xây Dựng Một Ngôi Nhà

Sự khác biệt về mức độ trừu tượng và quyền tự quyết.

Ngôn ngữ lập trình Vật liệu thô

Gạch, xi măng, sắt thép, cưa, búa.

  • Bạn có quyền tự do tuyệt đối: muốn đóng cái bàn hay xây tòa lâu đài đều được.
  • Đánh đổi: Mất nhiều thời gian nếu phải tự trộn hồ, tự đúc từng viên gạch từ đầu.

Thư viện (Library) Nội thất đúc sẵn

Cửa sổ, bóng đèn, bồn rửa chén mua sẵn.

  • Không cần tự chế tạo lại cái bóng đèn.
  • Bạn toàn quyền quyết định: mua hãng nào, lắp ở phòng nào, khi nào bật công tắc.

Framework Bản vẽ & Khung nhà

Móng, cột trụ, hệ thống điện nước định sẵn.

  • Định sẵn phòng khách ở đâu, nhà vệ sinh ở góc nào, chuẩn an toàn chịu lực.
  • Bạn chỉ việc xây tường và trang trí vào đúng các ô trống quy định.

2. Bản Chất Kỹ Thuật & Đảo Ngược Điều Khiển (IoC)

Điểm khác biệt cốt lõi nhất giữa Thư viện và Framework nằm ở câu hỏi: "Ai gọi Ai?"

Khi dùng Thư viện (Library) Bạn nắm quyền

Code của bạn làm chủ luồng chạy chính (Main Flow). Khi cần tính toán, xử lý chuỗi hay vẽ biểu đồ, bạn chủ động gọi hàm của thư viện.

Code của bạn → gọi hàm → Library → trả kết quả
  • Dễ dàng thay thế thư viện này bằng thư viện khác.
  • Ví dụ: NumPy, Pandas, Lodash, Axios, Dapper.

Khi dùng Framework Inversion of Control

Framework nắm giữ luồng điều khiển chính (HTTP lifecycle, DI Container, Security). Khi có sự kiện, Framework sẽ tự gọi vào code của bạn.

Framework → kích hoạt → Code của bạn → phản hồi
  • Bắt buộc tuân thủ quy ước thư mục, lifecycle và kiến trúc của Framework.
  • Ví dụ: ASP.NET Core, NestJS, Spring Boot, Django.

4. Ví Dụ Thực Tế: API Đăng Ký Người Dùng

So sánh giữa viết thuần bằng Ngôn ngữ và xây dựng trên Framework.

Trước khi dùng Framework (Code thuần)

Phải tự mở socket HTTP, tự đọc stream dữ liệu, tự parse JSON, tự bắt điều kiện URL và xử lý lỗi thủ công.

// Tự xử lý luồng request thô từ con số 0 if (req.url === '/api/register' && req.method === 'POST') { let body = ''; req.on('data', chunk => body += chunk); req.on('end', () => { // Tự parse JSON, tự validate, tự mở DB... }); }

Sau khi dùng Framework (NestJS / ASP.NET)

Routing, parse body, kiểm tra hợp lệ (Validation) và bảo mật đã có Framework tự động thực hiện.

// Chỉ tập trung viết đúng logic nghiệp vụ @Controller('auth') export class AuthController { @Post('register') register(@Body() dto: CreateUserDto) { return this.authService.create(dto); } }
